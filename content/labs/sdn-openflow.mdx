## 🧠 Théorie : pourquoi dissocier contrôle et données ?

```
   SWITCH TRADITIONNEL                  SWITCH SDN (OpenFlow)
   ───────────────────                  ─────────────────────
   
   ┌──────────────────────┐             ┌──────────────────────┐
   │  Control plane       │             │  Control plane       │
   │  (CPU local)         │             │  (silicon vide)      │
   │  - routing daemons   │             │  - reçoit flow-mods  │
   │  - STP, LLDP, BGP    │             │  - retourne stats    │
   ├──────────────────────┤             ├──────────────────────┤
   │  Data plane (ASIC)   │             │  Data plane (ASIC)   │
   │  - forward MAC table │             │  - flow tables       │
   └──────────────────────┘             └──────────┬───────────┘
                                                   │ OpenFlow
                                                   ▼
                                        ┌────────────────────┐
                                        │  CONTROLLER (sw)   │
                                        │  - Ryu, ONOS, ODL  │
                                        │  - décide global   │
                                        └────────────────────┘
   
   Configurer 50 switches indépendants  Programmer UN contrôleur
   → BGP, OSPF, STP éparpillés          → policy globale
```

### Anatomie d'une flow rule

```
   match                       action            priority
   ────────                    ────────          ─────────
   eth_type=0x0800             output:2          100
   ip_dst=10.0.0.1
   tcp_dst=443
   
   match                       action            priority
   eth_type=0x0800             drop              50
   ip_dst=10.0.0.0/8

   match                       action            priority
   *                           goto:table=1      0
```

→ pipeline : le paquet matche la 1ère règle (priority 100). S'il rate, il essaie la 50. S'il rate, action par défaut.

## 📋 Étape 3 — Premier contrôleur Ryu : L2 switch

```python
# l2_learning.py
from ryu.base import app_manager
from ryu.controller import ofp_event
from ryu.controller.handler import set_ev_cls, MAIN_DISPATCHER, CONFIG_DISPATCHER
from ryu.ofproto import ofproto_v1_3
from ryu.lib.packet import packet, ethernet

class L2Switch(app_manager.RyuApp):
    OFP_VERSIONS = [ofproto_v1_3.OFP_VERSION]

    def __init__(self, *a, **k):
        super().__init__(*a, **k)
        self.mac_to_port = {}

    @set_ev_cls(ofp_event.EventOFPSwitchFeatures, CONFIG_DISPATCHER)
    def install_default(self, ev):
        # règle par défaut : envoyer tout au contrôleur
        dp = ev.msg.datapath
        ofp = dp.ofproto
        parser = dp.ofproto_parser
        match = parser.OFPMatch()
        actions = [parser.OFPActionOutput(ofp.OFPP_CONTROLLER, ofp.OFPCML_NO_BUFFER)]
        inst = [parser.OFPInstructionActions(ofp.OFPIT_APPLY_ACTIONS, actions)]
        mod = parser.OFPFlowMod(datapath=dp, priority=0, match=match, instructions=inst)
        dp.send_msg(mod)

    @set_ev_cls(ofp_event.EventOFPPacketIn, MAIN_DISPATCHER)
    def packet_in(self, ev):
        msg = ev.msg
        dp = msg.datapath
        ofp = dp.ofproto
        parser = dp.ofproto_parser
        in_port = msg.match['in_port']
        pkt = packet.Packet(msg.data)
        eth = pkt.get_protocols(ethernet.ethernet)[0]

        dpid = dp.id
        self.mac_to_port.setdefault(dpid, {})
        self.mac_to_port[dpid][eth.src] = in_port

        if eth.dst in self.mac_to_port[dpid]:
            out_port = self.mac_to_port[dpid][eth.dst]
        else:
            out_port = ofp.OFPP_FLOOD

        actions = [parser.OFPActionOutput(out_port)]
        if out_port != ofp.OFPP_FLOOD:
            match = parser.OFPMatch(in_port=in_port, eth_dst=eth.dst)
            inst = [parser.OFPInstructionActions(ofp.OFPIT_APPLY_ACTIONS, actions)]
            mod = parser.OFPFlowMod(datapath=dp, priority=1, match=match, instructions=inst)
            dp.send_msg(mod)

        out = parser.OFPPacketOut(datapath=dp, buffer_id=msg.buffer_id,
                                  in_port=in_port, actions=actions, data=msg.data)
        dp.send_msg(out)
```

## 📋 Étape 4 — Règles policy "block sauf HTTP"

```python
# inside l2_learning, après install_default :
# bloque tout entre h1 (port 1) et h2 (port 2) sauf TCP 80

match = parser.OFPMatch(in_port=1, eth_type=0x0800, ipv4_dst="10.0.0.2",
                        ip_proto=6, tcp_dst=80)
actions = [parser.OFPActionOutput(2)]
mod = parser.OFPFlowMod(datapath=dp, priority=100, match=match,
                        instructions=[parser.OFPInstructionActions(
                            ofp.OFPIT_APPLY_ACTIONS, actions)])
dp.send_msg(mod)

# drop tout le reste de 10.0.0.1 vers 10.0.0.2
match = parser.OFPMatch(in_port=1, eth_type=0x0800, ipv4_dst="10.0.0.2")
mod = parser.OFPFlowMod(datapath=dp, priority=50, match=match, instructions=[])
dp.send_msg(mod)
```

## 📋 Étape 5 — Quarantaine dynamique via API

Le contrôleur expose une API REST :

```python
# quarantine_api.py
from ryu.app.wsgi import ControllerBase, route, WSGIApplication

class QuarantineAPI(ControllerBase):
    @route('quarantine', '/quarantine/{ip}', methods=['POST'])
    def quarantine(self, req, ip, **kwargs):
        for dp in self.dpset.dps.values():
            # drop tout en provenance de cette IP
            match = parser.OFPMatch(eth_type=0x0800, ipv4_src=ip)
            mod = parser.OFPFlowMod(datapath=dp, priority=200, match=match, instructions=[])
            dp.send_msg(mod)
        return Response(status=200)
```

```bash
# Simule un SIEM qui détecte une compromission sur h1 (10.0.0.1)
curl -X POST http://localhost:8080/quarantine/10.0.0.1

# Mininet
mininet> h1 ping 10.0.0.2
# → 100% packet loss, h1 isolé en < 100ms
```

## 🧠 Pitfalls

❌ **`ofctl -O OpenFlow10` quand le switch parle 1.3** : commandes muettes.
❌ **Pas de flow par défaut** → premier paquet bloqué, contrôleur silencieux.
❌ **Contrôleur SPOF** : en prod, mode `--ofcontroller=tcp:c1:6633,tcp:c2:6633` (multi-controller).
❌ **Mininet en prod** : mininet est un simulateur de lab. Pour prod, OVS sur des vrais switches/serveurs.
❌ **Ignorer les compteurs `n_packets=0` pendant des heures** : la règle ne match pas ce que tu crois.

## 🚀 Pour aller plus loin

- **ONOS** vs **OpenDaylight** : contrôleurs production-grade (HA, clusters)
- **Faucet** : contrôleur opinionated pour campus (config YAML, pas de code)
- **P4** + **BMv2** : programmer le parseur de paquets, pas juste les règles
- **OVN** (Open Virtual Network) : couche par-dessus OVS pour gérer des "virtual networks" complets
- **Cilium** : OVS replacement basé eBPF, intégré k8s (cf. série homelab)
- **In-Band Telemetry (INT)** : utilise SDN/P4 pour mesurer la latence saut par saut en temps réel

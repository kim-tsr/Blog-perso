## 🎯 Objectif

Installer **ArgoCD**, créer une `Application` qui pull depuis Git, voir le déploiement automatique, et tester ce qui se passe quand le cluster s'éloigne de l'état désiré.

## 📋 Étape 1 — Installer ArgoCD

```bash
kubectl create namespace argocd
kubectl apply -n argocd \
  -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
kubectl wait --for=condition=available --timeout=300s \
  deployment/argocd-server -n argocd
```

Récupérez le mot de passe admin initial :

```bash
kubectl -n argocd get secret argocd-initial-admin-secret \
  -o jsonpath="{.data.password}" | base64 -d
```

Port-forward pour accéder à l'UI :

```bash
kubectl port-forward svc/argocd-server -n argocd 8080:443
# Ouvrez https://localhost:8080  (login: admin)
```

## 📋 Étape 2 — Préparer le dépôt Git

Dans un dépôt vide, créez `apps/whoami/deployment.yaml` :

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: whoami
spec:
  replicas: 2
  selector: { matchLabels: { app: whoami } }
  template:
    metadata: { labels: { app: whoami } }
    spec:
      containers:
        - name: whoami
          image: traefik/whoami
          ports: [ { containerPort: 80 } ]
```

Commitez et poussez.

## 📋 Étape 3 — Créer l'Application ArgoCD

```yaml
# argocd-app.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: whoami
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/<vous>/<repo>.git
    targetRevision: main
    path: apps/whoami
  destination:
    server: https://kubernetes.default.svc
    namespace: default
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
```

```bash
kubectl apply -f argocd-app.yaml
```

Dans l'UI, l'app passe **Syncing → Healthy** en quelques secondes.

## 📋 Étape 4 — Tester le drift

Modifiez manuellement le déploiement :

```bash
kubectl scale deployment whoami --replicas=5
```

Quelques secondes plus tard, ArgoCD ramène à **2 replicas** — c'est le `selfHeal` qui agit. C'est ça, GitOps : **le dépôt Git est la source de vérité**.

## 📋 Étape 5 — Tester le rollback

Modifiez l'image dans Git (`image: nginx`), commitez. ArgoCD synchronise. Revenez en arrière (`git revert`), ArgoCD redéploie l'ancienne version.

## ✅ Validation

- ArgoCD UI affiche l'app **Healthy + Synced**
- Modifier le déploiement à la main est annulé sous 1 minute
- `git revert` déploie l'ancienne version sans intervention

## 🚀 Pour aller plus loin

- Utilisez **ApplicationSets** pour générer N apps depuis un template
- Activez **Sync Waves** pour orchestrer l'ordre de déploiement
- Branchez **OPA Gatekeeper** pour valider les manifests avant synchronisation
